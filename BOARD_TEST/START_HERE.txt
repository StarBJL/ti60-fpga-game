R5.7 current candidate: BOARD_TEST/r5_7/README.txt
Use matched 200 / 202.083333 / 205MHz bit and ELF. Keep 720p baseline; 1080p trial reverts after 10s unless confirmed. 480p is not implemented.

Ti60 R5 上板包 / Board-test package

1. 加载 ti60_r5.bit。必须更新硬件；原R4 bit不支持新输入与分辨率切换。
2. 加载 ti60_r5_debug.elf（带统计，优先用于赛题验收），或ti60_r5_release.elf。
3. 串口115200 8N1；启动标识 TI60-R5-DUALVIDEO-20261024。
4. Windows独立上位机在完整工程dist/Ti60_R5_Windows_Console.zip；Linux运行Start_Control_Panel.sh。
5. F9 / 矩阵S15 / 上位机按钮切换720p60和1080p30。内部画布固定1280x720，1080p使用3:2最近邻放大。
6. 按docs/INPUT_GUIDE.html连接矩阵及CH9350L，数量步长F6/F7/F8=100/10/1。
7. manifest.json记录精确SHA256和目标工具时序。上板成绩待用户填docs/BOARD_TEST_PLAN.csv。

建议先彩条/空载确认显示模式，再递增压力。开发板未由本轮自动烧写；真实显示器、USB键盘、音频与负载上限尚待实板验证。
.launch是Efinity RISC-V IDE的JTAG启动文件；搬动完整工程后运行python tools/configure_launch.py，或手动选择本包ELF。
legacy_r4目录是历史参考，勿与R5 ELF混用于新功能验收。
