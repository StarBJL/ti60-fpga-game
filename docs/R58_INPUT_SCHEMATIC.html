两块扩展键盘，各自控制一个人物。

所有矩阵线均在1.8V Bank 1B。选中行拉低，其余行高阻；列上拉至1.8V。纯触点板只接这8根，不接3.3V或5V电源。先用断电通断档识别行列：S1—S4共有线为R0，S1/S5/S9/S13共有线为C0；其余同理。不能凭彩色排线顺序猜引脚。

CH9350L的4条连接

模块端主板端说明
TXJ7 32 / C5 / GPIOL_11接FPGA RX，3.3V逻辑
RXJ7 34 / A4 / GPIOL_09接FPGA TX，3.3V逻辑
VCCJ7 3 / VCC_5V原理图经R122 0Ω引出；确认实装和实测5V
GNDJ7 5 / GND模块与FPGA必须共地

确认实际模块的串口电平为3.3V；5V模块供电不代表UART可以输出5V。若模块TX实测为5V，需电平转换后再接FPGA。带大量RGB灯的键盘先关闭灯效并核对供电能力；不假定J7可以提供任意电流。

使用USB Host／下位机，SEL高；状态2为S1高、S0低。不同模块的拨码ON/OFF与逻辑电平可能相反，按丝印及模块说明确认。状态2接收固定帧57 AB 01 + 8字节HID报告，不是ASCII字符。保留双向TX/RX，以便发送状态应答。

软件需要这样启动三人

本次日志中的游戏均为auto=1、players=1：正在自动演示。不是等待第二、第三块键盘插入后才显示人物。R5.8增加两个明确入口，点击后直接关闭自动演示并开始普通三人新局。

  1. 连接日志串口（板载FT4232H的通道C，常见为/dev/ttyUSB2，以实际识别为准）。
  2. 点“启动萝卜三人合作”或“启动东方三人合作”。确认auto=0、players=3。
  3. P1用上位机；P2用USB键盘；P3用矩阵。未连接的角色仍显示，只是不移动。
  4. 压力模式保留单人；不要用压力预设验证三人角色。

矩阵P3：S2/S5/S6/S7上下左右，S8技能，S16慢速，Fn+S2/S3/S5选自己的升级。东方P3默认自动射击，S3切换；无二极管矩阵出现矩形鬼键时释放矩阵输入，全部松开后恢复。USB P2：WASD/方向、Z/空格射击、X/J技能、Shift慢速、1/2/3升级。

按键通路诊断

上位机每个遥测窗口显示矩阵原始位图、USB键盘报告数、UART错误与鬼键计数。S15短按切分辨率，单独长按2秒强制恢复720P；USB模块键盘F12也可恢复。Fn+S15仍为下一曲。S1对应bit0，S16对应bit15；单按S2应为0x0002。USB按下和松开应产生报告。键位0只能表示当前未按键，不能证明未接线。若USB报告一直0，先核对模块供电、Host状态2、共地、TX/RX和115200 8N1。

:1 coop 1          # 萝卜三人新局
:2 coop 0          # 东方三人新局
:3 status          # 看T7 players=3、I5输入状态
:4 video_recover   # 黑屏时请求720P并重启输出，需R5.8配套bit实现完整重启

显示兼容说明

R19固定640×480输出；R2的HDMI_720P是编译参数，软件启动读HDMI_RES适配；“#”只切换东方内部640×480／720P视图。它们没有运行时480P↔720P的HDMI时钟切换。R5.8保留正常720P路径，在切换时短暂停发并复位四路TMDS，再恢复输出；1080P DVI诊断关闭HDMI数据岛和声音，仅用于区分接收端问题。PH27QB2是否接受1080P30仍需EDID或实测，恢复程序不是显示器支持所有时序的保证。

English

The passive matrix uses eight 1.8V Bank 1B signals. CH9350L uses independent 3.3V UART pins J7 32/34 plus verified 5V on J7 3 and ground on J7 5. Verify the adapter numbering and actual matrix wire order; never infer it from cable colours. P1 is the debug UART console, P2 the CH9350L USB keyboard, and P3 the matrix. The explicit co-op buttons leave demo mode and start three players. Stress scenes remain single-player. This diagram supplements the original board schematic; physical wiring and module compatibility still require verification.
