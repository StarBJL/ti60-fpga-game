2. R19、R2的480P/720P并非HDMI热切换

版本物理输出软件兼容方式
R19 AUTO LOCATOR固定640×480；25MHz像素时钟，794×525总时序默认640×480画布
R2 ZH FULLHDMI_720P编译参数选择1280×720；74.375MHz，1650×750启动读取HDMI_RES设置pitch/画布；#键切东方内部640×480或720P视图
R5.8保持原720P；1080P30仍从720P画布按3:2最近邻放大新增切换期间停发/重启输出与恢复操作

R2的#键没有改物理HDMI时钟。其顶部HDMI_720P常量即使改为0，也要重新生成对应PLL和bit，不能直接当作运行时480P切换。R5.8没有声称增加480P输出；如后续加入，需要独立像素时钟、下采样和模式信息，保留720P分支。

3. 这次补了真正的输出重启

  1. 新的LNK8寄存器控制四路TMDS的OE和serializer RST；控制信号同步到像素域。正常情况下OE=1、RST=0，与原设计一致。
  2. 请求切换时先停发约150ms，保持内部时序/DMA运行；写入目标模式后等待至少两个完整帧和约150ms稳定时间。
  3. 释放serializer复位，再留四个像素时钟让输出稳定后开启四路OE。之后才启动1080P的10秒确认倒计时。
  4. 如果模式确认或帧计数在1秒内不正常，重新请求720P并释放输出，不无限保持黑屏。
  5. 新增1080P DVI诊断：暂时关闭HDMI数据岛和音频。DVI覆盖仅在1080模式生效，720P仍为原HDMI音视频路径。

依据Ti60数据手册第35页的LVDS TX RST/OE接口。用户显示器的模拟接收与锁定未建模，输出重启通过仿真仍需要实屏确认。

黑屏时不要点“我已看见画面，取消自动回退”。直接点“黑屏恢复720P”，或者USB模块键盘F12；矩阵S15单独长按2秒也会恢复。S15短按仍切分辨率，Fn+S15仍为下一曲。

4. 三个人物如何打开

R5.7的自动演示只生成一名角色。新上位机提供“启动萝卜三人合作”和“启动东方三人合作”，关闭自动演示、退出压力状态，直接开始普通三人新局，回报auto=0、players=3。不需要等两个外设都插上才显示三个人物；未接入的玩家只是站在原地。

P1=PC串口/上位机；P2=CH9350L USB键盘；P3=16键矩阵。压力模式保持单人。三人玩法和已加入的DSP Alpha/add特效沿用R5.7。

5. 两个扩展键盘怎么接

打开完整双键盘接线原理图或矢量图。主板厂商原理图保留，新增这张外设连接附图；引脚依据原理图与本工程约束核对。

外设连接
矩阵R0/R1/R2/R3J7 2 / 4 / 8 / 10
矩阵C0/C1/C2/C3J7 20 / 22 / 26 / 28；全部1.8V Bank 1B
CH9350L TX / RXTX→J7 32（FPGA RX），RX←J7 34（FPGA TX）；3.3V UART
CH9350L VCC / GND经确认的J7 3脚5V / J7 5脚GND；供电与UART电平分别核对

CH9350L设USB Host/下位机，SEL高、S0低、S1高，状态2，115200 8N1。矩阵8线顺序用断电通断档确认，不按颜色猜。上位机新增矩阵原始位图、USB报告数和错误计数；单按S2应为0x0002。

The board log contains54 game windows, all in single-player autoplay. R5.8 adds explicit co-op start commands/buttons that exit demo/stress and start three independent players. Matrix and USB input diagnostics make wiring checks visible. The wiring addendum specifies all eight1.8V matrix signals and both3.3V UART signals plus5V/GND for CH9350L.

R19 is fixed480p and R2 selects720p at elaboration; R2's # command changes the internal Touhou view, not physical HDMI timing. R5.8 preserves steady720p behavior and adds synchronized control of all four TMDS OE/reset signals for bounded link restart. Emergency720p recovery is available in the console, USB F12 and a2-second solo hold of matrix S15. An1080-only DVI diagnostic isolates HDMI data-island compatibility and intentionally has no audio. The PANDA PH27QB2 blackout is not claimed resolved without physical retesting.480p switching is not implemented.
