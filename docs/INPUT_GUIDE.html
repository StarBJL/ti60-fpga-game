接线前核对

主板原理图的 J7 与手册表格部分不一致，表中依据 PDF 第 9、11 页交叉追踪。绿色 2×20 转接排针的方向与针号要用通断确认；照片无法确定 8 根彩线的行列顺序。纯触点矩阵只要这 8 根信号，不另接 VCC/GND。

怎样用万用表确认行列和 S1—S16
  1. 拔掉供电，把矩阵板与 FPGA 分离；确认它是纯触点矩阵。
  2. 按住 S1，找出唯一接通的一对排针；分别与 S2、S3、S4 对照，共有的线是 R0。
  3. 用 S5—S8、S9—S12、S13—S16 找出 R1、R2、R3。
  4. 按 S1、S5、S9、S13 找 C0，同理得到 C1—C3；贴上标签后再按表接线。
  5. 核对绿色 2×20 排针和主板 J7 的通断；上电前测量 Bank 电压与共地，不凭排线颜色判断。
USB HOST → UART

键盘模块用 5 V 供电，UART 信号接 3.3 V Bank。

SEL=高 选择下位机 / USB Host；S0=低、S1=高 选择工作状态 2。拨码 ON/OFF 与电平的对应由具体模块决定。选购后核对模块版本、电源和串口电平，不能把芯片引脚的耐受值当作整个模块的保证。

热拔插需实测

状态 2 按变化上报，长按时可能没有新串口数据。不能用 300 ms 静默判定松开。驱动在明确断连、串口错误或恢复流程中调用 input_keyboard_release()；若模块掉电未发释放报告，单靠 RX 无法自动判断。PC 端心跳租约与实体保持态分别管理。首次真实实体按键动作（包括只按开始键）会标记已使用物理输入，松开后不会意外回到旧终端自动射击；仅上电探测到外设不改变控制方式。

协议与兼容性边界

解析器接受键盘 57 AB 01 + 8 bytes，完整忽略鼠标 57 AB 02 + 4 bytes，处理状态消息；先排空 RX FIFO 后，不完整帧持续空闲超过 20 ms 才丢弃；避免将正常帧跨慢帧轮询误判为线上截断，USB ErrorRollOver/POSTFail/ErrorUndefined 释放保持态。当前不支持状态 0/1、多媒体键或专用 NKRO 报告。状态 2 不运行状态 0/1 启动握手，但 57 AB 80 + status 需要应答：排空 RX 后连续发送 57 AB 12 00 00 00 00 00 FF 00 20，线上约 0.96 ms，软件等待超时 20 ms。LED 字段固定为灭；这项实现尚待真实模块验证。

ENGLISH SUMMARY

Eight wires connect a sixteen-key passive matrix.

The keypad uses four open-drain scanned rows and four columns pulled up to 1.8 V in Bank 1B. J7 pins 2/4/8/10 are rows; 20/22/26/28 are columns. Verify the real cable order and the green 2×20 adapter orientation. S4 is Fn, S11 cycles count steps 100/10/1, S12 cycles size, and S15 switches physical video modes.

CH9350L is configured as USB Host/downstream, state 2: SEL high, S0 low, S1 high. Connect module TX to J7 32 (FPGA RX), module RX to J7 34 (FPGA TX), plus verified 5 V power and common ground. UART is 115200 8N1 at 3.3 V logic. Parse the fixed boot-keyboard frame, not ASCII or state-0/1 variable frames. The state-2 status frame receives the implemented eleven-byte reply; real-module verification is pending. Reports are change-driven; silence alone is not proof of unplugging.

R5.7 normal games use independent UART/USB/matrix players with shared enemies and stages. Pressure scenes remain single-player. Matrix P3 auto-fire is on by default in normal Touhou; S3 toggles it. Both HDMI modes render at 1280×720. Physical 1080p30 is a 3:2 nearest-neighbor enlargement, not native 1080 rendering. The current PLL produces approximately 60.101 / 30.051 Hz. The 720p display path is preserved. The reported monitor blackout at 1080p is not yet resolved; R5.7 adds a 10-second confirmation timeout. 480p is a design proposal, not an available mode. Count limits are allocated capacities, not stable-frame-rate claims. Use 720p mode for the contest’s 60 FPS Alpha + Color Key challenge and fill in board results after measurement.
