GitHub upload method / GitHub 上传说明

Target: https://github.com/18971355314bjl-gif/ti60-fpga-game (private).
Ordinary source files, assets, binaries and logs are uploaded as exact Git blobs.
Each uploaded blob is compared against the local Git SHA; large-file restoration
also checks SHA256 and byte length before replacing the destination atomically.

Automatic approval review rejected adding a separate asset-import Actions
workflow with contents: write that executes import code and pushes a branch.
Its stated reason was that project-upload authorization did not specifically
authorize that persistent, security-sensitive repository automation.
That rejected workflow was not installed or run. The upload continues through
ordinary GitHub blob/tree APIs. Files that exceed the API's accepted request
size are preserved losslessly in checked archive parts, with an explicit local
restore script. No alternate workflow is used to bypass the rejected action.
