# 声音库清单：tools/wav2bank.py 读这个文件，生成 sound/sound_bank.bin + sound_bank.S
# （make SOUND=1 时链接进 game.elf，下载后在 DDR 0x02000000）。
#
# 每行：名字  WAV 文件（相对本文件）  选项...
#   名字 <= 15 个字符；游戏按名字找声音（src/th_sound.h），清单里没有的事件就不响。
#   选项：mono / stereo（音效默认单声道，bgm 开头的默认保留立体声）
#         rate=N（降采样省空间；不写 = 保持原采样率，混音器播放时自己换算到 48 kHz）
#         loop=auto（WAV 里的 smpl 循环点，没有就整首循环；bgm 默认）| loop=none（音效默认）
#         loop=N（帧号）| loop=12.5s（秒）   gain=0.7 或 gain=-3dB   trim（去掉开头静音）   end=60s
#         8bit（8 位，体积减半，有底噪，适合噪声类音效）
#
# 把 WAV 放进 sound/ 下面（比如 sound/se/、sound/bgm/），改好下面的行，然后：
#     python tools/wav2bank.py
# 再 build_game.bat（声音库变了 make 会自动重新汇编 sound_bank.S）。
# 还没有自己的 WAV 时：python tools/wav2bank.py --demo  生成一套合成的占位音效和 BGM。
#
# 体积 / 下载时间：库会跟 elf 一起经 JTAG 下载。立体声 44.1 kHz 16 位 = 每分钟 10 MB；
# BGM 用 rate=32000 或 22050、音效用 rate=22050 mono 可以小很多（总共上限 16 MB）。
#
# ---- 音效（事件名见 src/th_sound.h）----
# shot           se/plst00.wav      rate=22050 trim
# enemy_fire     se/tan00.wav       rate=22050 trim
# hit            se/damage00.wav    rate=22050 trim
# kill           se/enep00.wav      rate=22050
# graze          se/graze.wav       rate=22050 trim
# item           se/item00.wav      rate=22050 trim
# powerup        se/powerup.wav
# extend         se/extend.wav
# bomb_get       se/cardget.wav
# bomb           se/slash.wav
# death          se/pldead00.wav

# capture        se/cardget.wav
